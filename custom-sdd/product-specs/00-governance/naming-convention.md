# Naming Convention

- Services use lowercase kebab case, for example `service-a`.
- Features use stable names such as `feature-01`.
- Feature artifacts use fixed names: `spec.md`, `business-rules.md`, `api.md`, `data.md`, `test-spec.md`, `guidelines.md`, and `change-history.md`.
- IDs use uppercase prefixes followed by stable numbers.

Dummy owner team: `service-a-team`.
