# Explore Blueprint Journey

## Scenario

A user wants to understand the complete specification-driven development blueprint.

## Flow

1. User opens the website.
2. User sees the folder tree and Markdown preview.
3. User selects `00-index.md`.
4. User follows links or terminal commands to open related docs.
5. User expands `product-specs` to inspect the example repository.

## Acceptance Criteria

- `AC-JOURNEY-001`: The user can open every root blueprint Markdown file.
- `AC-JOURNEY-002`: The user can open every Markdown file under `product-specs`.
- `AC-JOURNEY-003`: The current path remains visible while reading.
