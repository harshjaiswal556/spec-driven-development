# Repository Hygiene

## Objective

Keep the React project repository clean by committing source files and specifications while excluding dependencies, generated output, local machine configuration, logs, and build artifacts.

## Required Git Ignore Rules

The root `.gitignore` must exclude:

- `node_modules/`
- `dist/` and `build/`
- `src/generated/docs.js`
- `.env` and `.env.*`, except `.env.example`
- log files
- tool caches
- coverage and test reports
- common operating-system and editor files

## Generated Content

`src/generated/docs.js` is produced by `npm run generate-content`. It must remain reproducible from the source Markdown files and should not be edited manually.

## Acceptance Criteria

- `AC-GOV-REPO-HYGIENE-001`: The React project root contains `.gitignore`.
- `AC-GOV-REPO-HYGIENE-002`: Dependency and build folders are ignored.
- `AC-GOV-REPO-HYGIENE-003`: Generated document content is ignored and regenerated by app scripts.
- `AC-GOV-REPO-HYGIENE-004`: Local environment files are ignored without blocking a future `.env.example`.
