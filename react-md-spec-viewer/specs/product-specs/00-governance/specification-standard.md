# Specification Standard

## Required Feature Sections

Feature specs should include objective, actors, preconditions, trigger, flows, error scenarios, data requirements, UI requirements, accessibility requirements, performance expectations, acceptance criteria, dependencies, and open questions.

## Metadata

Each detailed feature spec should include stable metadata with `spec_id`, `title`, `version`, `status`, and `owner_team`.

## Acceptance Criteria

Acceptance criteria must be testable and reference visible product behavior.

## Open Questions

Open questions must remain explicit. Implementation must not silently resolve them.
