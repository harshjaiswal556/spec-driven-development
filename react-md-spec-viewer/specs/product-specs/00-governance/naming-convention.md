# Naming Convention

## Folders

Use kebab-case folder names for app modules and features.

## Specs

Use stable, descriptive files such as `spec.md`, `api.md`, `data.md`, `test-spec.md`, `guidelines.md`, and `change-history.md` for feature folders.

## UI Labels

Document titles should be derived from Markdown H1 text when available. File paths should remain visible in compact form for orientation.
