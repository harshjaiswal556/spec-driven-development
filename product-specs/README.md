# Product Specifications

Dummy specification repository for a fictional product called **OrbitDesk**.

This repository follows the Specification-Driven Development model:

- Product intent lives in `01-product/`.
- Service and feature specifications live in `03-services/`.
- Current Markdown is the approved source of truth.
- Git commits and tags preserve historical versions.
- `change-history.md` maps versions to JIRA and commits.

Start with `00-governance/specification-standard.md`, then inspect `03-services/service-a/feature-01/` as the complete example.

All values in this repository are dummy data.
