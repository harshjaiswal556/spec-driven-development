# Metadata Standard

Approved feature Markdown begins with YAML metadata.

```yaml
spec_id: SVC-A-F01
title: Customer Registration
service: service-a
version: 1.0
status: APPROVED
owner_team: service-a-team
jira_tickets:
  - DEMO-101
related_adrs:
  - ADR-001
```

Stable IDs are required for specifications, business rules, APIs, acceptance criteria, and ADRs.
