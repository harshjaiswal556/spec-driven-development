# AI Development Guidelines

1. Resolve the JIRA ticket and specification before coding.
2. Retrieve only the smallest sufficient context.
3. Treat open questions as blockers; do not invent behavior.
4. Update tests with implementation changes.
5. Report assumptions, risks, and validation results.
6. Stop when the specification and code disagree on intended behavior.

Dummy example: for `DEMO-101`, retrieve the registration rules, API contract, data model, tests, and relevant ADRs only.
