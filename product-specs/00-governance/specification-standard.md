# Specification Standard

## Required Feature Sections

Every approved feature specification should define objective, actors, preconditions, trigger, flows, errors, rules, inputs, outputs, API, data, security, performance, observability, acceptance criteria, tests, dependencies, JIRA tickets, ADRs, and open questions.

## Metadata Example

```yaml
spec_id: SVC-A-F01
title: Customer Registration
service: service-a
version: 1.0
status: APPROVED
owner_team: service-a-team
jira_tickets:
  - DEMO-101
```

Use stable identifiers such as `BR-REG-001`, `AC-REG-001`, and `API-REG-001`.
